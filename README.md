# Meme Coin Trading Platform

A real-time meme coin monitoring and trading platform with Pump.fun API integration.

## Features

- Real-time coin monitoring via Pump.fun API
- Mock data fallback for testing
- Solana RPC integration for on-chain data
- Market cap and holder count tracking
- Database persistence

## Setup

```bash
pip install -r requirements.txt
python app.py
```
